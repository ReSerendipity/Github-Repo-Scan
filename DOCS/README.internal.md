# github-repo-scan 对内项目说明（维护者专用）

> 本文件位于 `DOCS/`，由根目录 `AGENTS.md` 引用；根目录 `readme.md` 一律对外。

**客户端脚本专项守卫**（重要）：`renderDashboard` 用模板字面量拼 HTML，客户端 `<script>` 里的 `\n`、`\r`、`\s` 等会被外层模板「吃掉」（`\n`→真换行、`\s`→`s`），轻则逻辑错误、重则整个脚本语法错误导致页面永久卡在「正在载入…」。测试用 `vm.Script` 实际解析每个脚本块、断言不含裸 CR，并扫描「调用了服务端专有函数却没自带定义」的引用，防止此类问题复现。

**提交前必须运行**：改动 `scan-core.mjs` 等核心逻辑后，需本地 `node --test` 全绿再提交。
